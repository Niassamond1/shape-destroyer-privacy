# Shape Destroyer — Privacy (public site)

Copy **everything in this folder** into a **new public** GitHub repo
named `shape-destroyer-privacy` (or any name — then adjust the URL).

## Setup

1. Create a **public** repo on GitHub (example name: `shape-destroyer-privacy`).
2. Upload / push this folder’s contents so `index.html` is at the **repo root**
   (or under `/docs` if you prefer Pages from docs).
3. Repo → **Settings → Pages**
   - Source: Deploy from a branch
   - Branch: `main` (or `master`)
   - Folder: `/ (root)` — or `/docs` if you put the file there
4. Wait ~1 minute. Open:

`https://niassamond1.github.io/shape-destroyer-privacy/`

5. Paste that URL into Google Play Console → App content → Privacy policy.

## Keep in sync

When the game’s privacy text changes, update this `index.html` **and**
the in-app `privacy.*` strings in the private game repo.
