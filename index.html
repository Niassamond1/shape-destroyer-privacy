Shape Destroyer

Privacy Policy · Updated August 2026

Summary

Shape Destroyer is a local-first game. Progress lives mainly on your device in an encrypted database. Cloud features (account, save sync, notifications) use Google Firebase when you sign in. Weekly Event leaderboards, seasons, and reward delivery use Supabase.

What we may collect

  • Account email and ID if you sign in (Firebase Auth).
  • Optional encrypted cloud save of game progress (Firebase).
  • Push notification token for inbox messages and event rewards (FCM).
  • Bug reports you choose to send (title and description).
  • Usage analytics on Android/iOS (screens and key game events) via Firebase Analytics — not on Windows.
  • Crash diagnostics on Android/iOS via Firebase Crashlytics (stack traces and device info).
  • Gameplay data stored on your device (encrypted), including Weekly Event tickets and pending offline run queues in your local save.
  • When signed in and playing Weekly Events: run results (level reached, kill score / duration, Firebase user id, display name) and FCM token for reward delivery via our Supabase backend.

How we use it

We use this data to run your account, restore progress across devices, send in-game messages, improve the game from reports, understand which features are used, and operate Weekly Events (leaderboards and season rewards). Campaign play works offline; event rankings require sign-in. We do not sell your personal data.

Storage

Progress lives mainly on your device (encrypted). Cloud saves and account data are stored in Firebase when you sign in and sync. Weekly Event leaderboard rows and season data are stored in Supabase (PostgreSQL) via secure server functions. Analytics events are processed by Google Firebase. Logging out can wipe the local encrypted database on this device.

Analytics

On mobile we measure app opens, screens visited, and actions such as login, starting/finishing a run, opening chests, cloud save, and bug reports. Events are aggregated and do not include your email or player name. Analytics is not collected on the Windows build.

Sharing

Data is processed through Firebase (Google) for authentication, database, messaging, and analytics, and through Supabase for Weekly Event leaderboards, seasons, and reward pushes. We do not share your data with other advertisers. Staying signed out avoids event cloud features (campaign still works locally).

Account deletion

In the app (Account screen), signed-in players can delete their account. This removes Firebase Auth credentials and cloud nodes we control for that user (profile, FCM token, cloud save, inbox). Local encrypted data on the device is wiped. Timed-event leaderboard rows in Supabase may remain until purged as part of event cleanup. Bug reports already submitted may remain for support until purged by staff. Analytics aggregates already processed by Google are not personally reversed.

Contact

You can reach us at destroyershape@gmail.com for any privacy or support questions. You may also use the in-app bug report after signing in, or contact the developer through the Google Play store listing.

Resumo

Shape Destroyer é um jogo local-first. O progresso fica principalmente no seu aparelho, em banco criptografado. Recursos na nuvem (conta, sync, notificações) usam Google Firebase quando você entra. Rankings, temporadas e entrega de recompensas dos Eventos Semanais usam Supabase.

O que podemos recolher

  • E-mail e ID da conta se você entrar (Firebase Auth).
  • Save opcional criptografado do progresso (Firebase).
  • Token de notificação para mensagens da inbox e recompensas de eventos (FCM).
  • Reportes de bug que você enviar (título e descrição).
  • Analytics de uso no Android/iOS (telas e eventos-chave) via Firebase Analytics — não no Windows.
  • Diagnóstico de crashes no Android/iOS via Firebase Crashlytics (stack traces e info do aparelho).
  • Dados de jogo no dispositivo (criptografados), incluindo tickets de Eventos Semanais e fila de corridas pendentes no save local.
  • Quando logado e jogando Eventos Semanais: resultados (nível, pontuação de kills / duração, ID Firebase, nome) e token FCM para recompensas via nosso backend Supabase.

Como usamos

Usamos esses dados para conta, restaurar progresso, enviar mensagens, melhorar com reportes, entender o uso das funções e operar Eventos Semanais (ranking e recompensas da temporada). A campanha funciona offline; o ranking de eventos exige login. Não vendemos seus dados pessoais.

Armazenamento

O progresso fica principalmente no seu aparelho (criptografado). Saves na nuvem e dados de conta ficam no Firebase quando você entra e sincroniza. Ranking e temporadas de eventos ficam no Supabase (PostgreSQL) via funções seguras no servidor. Eventos de Analytics são processados pelo Google Firebase. Sair da conta pode apagar o banco local criptografado neste dispositivo.

Analytics

No mobile medimos abertura do app, telas e ações como login, começar/terminar corrida, baús, save na nuvem e reportes. Os eventos são agregados e não incluem e-mail nem nome do jogador. Analytics não é coletado no build Windows.

Compartilhamento

Os dados passam pelo Firebase (Google) para auth, banco, mensagens e analytics, e pelo Supabase para ranking, temporadas e push de recompensas dos Eventos Semanais. Não compartilhamos com outros anunciantes. Ficar desconectado evita os recursos de evento na nuvem (a campanha ainda funciona localmente).

Exclusão de conta

No app (tela Conta), jogadores logados podem excluir a conta. Isso remove as credenciais do Firebase Auth e os nós na nuvem que controlamos para esse usuário (perfil, token FCM, save, inbox). Os dados locais criptografados no aparelho são apagados. Linhas de ranking no Supabase podem permanecer até limpeza do evento. Reportes de bug já enviados podem permanecer para suporte até a equipe limpar. Agregados de Analytics já processados pelo Google não são revertidos individualmente.
